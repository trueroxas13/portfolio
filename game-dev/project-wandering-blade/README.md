IMPORTANT NOTE:
Interacting with objects in the game to trigger events can only be done with the E key as of now. 
The demo works best with a controller, but keyboard and mouse controls have also been implemented. Mouse sensitivity may be buggy sometimes.

C O N T R O L L E R
(Playstation and Xbox Variants)

Up/Down D-Pad : Navigate Main/Actions Menu
Left Stick : Move        Right Stick : Look
X/A : Confirm/Perform Action
Square/X : Dash (While Moving)
O/B : Return/Jump
Start/Options : Pause/Unpause

K E Y B O A R D / M O U S E

WSAD : Move / Navigate Main Menu        Mouse : Look
Left Click : Perform Action
Right Click : Dash (While Moving)
Mouse Scroll : Navigate Main/Actions Menu
Space : Jump / Confirm
Esc : Return/Pause
