| Use case id: 101                                 | Register/ Renew Registration Vehicle.                                                                                                                                                                          |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brief description                                | Allows a vehicle owner to register a new vehicle by providing necessary details, purchasing insurance, and completing payment.                                                                                 |
| Primary actors                                   | Vehicle Owner, Insurance Company                                                                                                                                                                               |
| Trigger(s)                                       | Registration/ Registration Renewal service is requested.                                                                                                                                                       |
| Preconditions:                                   | 1. Vehicle owner must exist as a customer in the system.<br>2. Vehicle owner must have an insurance policy for the new vehicle yet to be registered.<br>3. VIN must be valid and verified by the manufacturer. |
| Post-conditions:                                 | 1. A new registration sticker is assigned. <br>2. The insurance policy is attached to the vehicle registration.                                                                                                |
| Normal scenario (Response Table):                |                                                                                                                                                                                                                |
| Actor Action                                     | System Response                                                                                                                                                                                                |
| 1. Vehicle owner enters the VIN into the system  | 2. Retrieves the registration details and checks if the vehicle is over two years old. (2a)                                                                                                                    |
|                                                  | 3. Request the compulsory insurance policy.                                                                                                                                                                    |
| 4. Insurance Company sends the insurance policy. |                                                                                                                                                                                                                |
|                                                  | 5. Checks for any unpaid fines for traffic offenses. (5a)                                                                                                                                                      |
|                                                  | 6. Creates a new registration with the same validation period as specified in the new insurance policy.                                                                                                        |
|                                                  | 7. Insurance policy and the fitness certificate are then attached concurrently with the vehicle registration.                                                                                                  |
|                                                  | 8. System makes an invoice for the registration renewal.                                                                                                                                                       |
| Alternative flows:                               |                                                                                                                                                                                                                |
| 2a                                               | If the vehicle is over 2 years old and doesn't have a fitness certificate, the system displays the message “Get fitness certificate first”.                                                                    |
| 5a                                               | If there are unpaid traffic fines, the system terminates with the message "Pay the bill first" <<extend: Make Payment>>.                                                                                       |

| Use case Id: 102                                               | Transfer Registered Vehicle Ownership.                                                                                                    |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Brief description                                              | Handles the transfer of ownership for a previously registered vehicle from one owner to another.                                          |
| Primary actors                                                 | Vehicle Owner                                                                                                                             |
| Trigger(s)                                                     | Transfer service is requested.                                                                                                            |
| Preconditions:                                                 | 1. Vehicle must be registered.<br>2. Vehicle's ownership is verified.<br>3. Current vehicle owner must exist as a customer in the system. |
| Post-conditions:                                               | Ownership is transferred.                                                                                                                 |
| Normal Scenario (Response Table):                              |                                                                                                                                           |
| Actor Action                                                   | System Response                                                                                                                           |
| 1. Current owner enters the VIN of the registered vehicle      |                                                                                                                                           |
| 2. Current owner enters his QID number                         | 3. Initiate the transfer process (3.a.)                                                                                                   |
|                                                                | 4. Check for any unpaid invoices for registration fees or traffic fines (4a.)                                                             |
|                                                                | 5. Request the new owner's details                                                                                                        |
| 6. Current owner provides the mobile phone number of new owner | 7. Assign the vehicle to the new owner                                                                                                    |
|                                                                | 8. Designate the current owner as the ‘previous owner’                                                                                    |
|                                                                | 9. Designate the new owner as the ‘current owner’                                                                                         |
|                                                                | 10. Generate a new registration sticker                                                                                                   |
|                                                                | 11. Creates an invoice for the transfer fee.    x                                                                                          |
| Alternative flows:                                             |                                                                                                                                           |
| 3a.                                                            | If the retrieved information does not match the provided data, system terminates session with the message “Incorrect Information”.        |
| 4a.                                                            | If there are any unpaid bills, system terminates the session with the message “Pay the bills first”.                                      |
|Special Requirements |
|Notification System|After the transfer is successfully completed, the system must send an email or in-system notifications to both the new owner and the existing owner to confirm.
|Transfer Vehicle Guidelines|The interface should offer straightforward, step-by-step guidance during the transfer process, allowing users to navigate easily and complete all necessary actions.

| Use case Id: 103                                                                         | Report Accident                                                                                                                                                                 |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brief description                                                                        | This use case allows the vehicle owner to report an accident between two vehicles.                                                                                              |
| Primary actors                                                                           | Vehicle Owner, Insurance Company.                                                                                                                                               |
| Trigger(s)                                                                               | Current vehicle owner enters the VIN of the registered vehicle and his QID.                                                                                                     |
| Preconditions:                                                                           | 1. The accident must involve exactly two vehicles.<br>2. There should be no dispute regarding fault.                                                                            |
| Post-conditions:                                                                         | 1. An accident report is generated and sent to the insurance company.<br>2. Both parties and authorized workshops can access the report using the case number.                  |
| Normal Scenario                                                                          |                                                                                                                                                                                 |
| Actor Action                                                                             | System Response                                                                                                                                                                 |
| 1. One of the vehicle owners has to enter the VIN of both his vehicle and victim vehicle |                                                                                                                                                                                 |
|                                                                                          | 2. finds vehicle details and registration information for both vehicles. (2a)                                                                                                   |
|                                                                                          | 3. asks to provide the date, time, location, and a brief accident description.                                                                                                  |
| 4. Reporter provides the date, time, location, and a brief accident description.         |                                                                                                                                                                                 |
|                                                                                          | 5. records this information, and by default, it sets that the vehicle that entered all information is the offending vehicle’s owner.                                            |
|                                                                                          | 6. asks the owner of the offending vehicle to confirm this.                                                                                                                     |
| 7. Reporter (Vehicle Owner) confirms the information.                                    | 8. records this information. (8a.).                                                                                                                                             |
|                                                                                          | 9. Concurrently finds the insurance policy of the offending vehicle and creates an accident report with a unique case number.                                                   |
|                                                                                          | 10. Sends the accident report to the insurance company.                                                                                                                         |
| 11. Insurance company sends an acknowledgement receipt.                                  | 12. Saves the acknowledgement receipt.                                                                                                                                          |
| Alternative flows:                                                                       |                                                                                                                                                                                 |
| 2a.                                                                                      | If the system fails to find one (or both) of the VIN of the vehicles, terminates with the message "Wrong vehicle info or vehicle not found."                                    |
| 8a.                                                                                      | If the reporter denies the information, asks the user to re-enter the information or cancel the report.                                                                         |
| Special Requirements                                                                     |                                                                                                                                                                                 |
| Document Upload Capability                                                               | Users should have the ability to upload relevant documents, including images of the accident scene, evidence of vehicle damage, and police reports, directly within the system. |
| Automated Notifications                                                                  | The system should automatically inform relevant authorities, insurance providers, and involved parties when the accident report is submitted.                                   |

| Use case Id: 104                                                                       | Issue Confiscation Order.                                                                                                                                             |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brief description                                                                      | This use case describes the process of issuing a confiscation order by a police officer for a vehicle due to red-light offenses.                                      |
| Primary actors                                                                         | Traffic Police Officer                                                                                                                                                |
| Trigger(s)                                                                             | Traffic police officer enters a period and selects a red-light offense type                                                                                           |
| Preconditions:                                                                         | 1. The vehicle must have an existing registration.<br>2. Vehicles must exceed a certain number of red-light offenses during a specified period by the officer.        |
| Post-conditions:                                                                       | 1. The vehicle's registration is canceled.<br>2. The vehicle owner is notified of the confiscation order.<br>3. The order is broadcasted to all police departments.   |
| Normal Scenario                                                                        |                                                                                                                                                                       |
| Actor Action                                                                           | System Response                                                                                                                                                       |
| 1. Traffic officer enters the period                                                   |                                                                                                                                                                       |
| 2. Traffic officer selects the redlight offence type                                   | 3. find list of vehicles that match criteria. (3a.), (3b.).                                                                                                           |
| 4. Traffic officer selects vehicles that exceed a certain number of red-light offences | 5. create confiscating order for those vehicles                                                                                                                       |
|                                                                                        | 6. ask for confirmation from traffic police                                                                                                                           |
| 7. Traffic officer confirmations request                                               | 8. save confirmation. (8a.)                                                                                                                                           |
|                                                                                        | 9. cancel registration of specified vehicles                                                                                                                          |
|                                                                                        | 10. inform each vehicle owner of registration cancelation                                                                                                             |
|                                                                                        | 11. broadcast orders to all police departments.                                                                                                                       |
| Alternative flows:                                                                     |                                                                                                                                                                       |
| 3a.                                                                                    | if the criteria is invalid no matching vehicles found, returns to selection page\|                                                                                    |
| 8a.                                                                                    | If confirmation was disapproved by traffic officer, cancels confiscation order                                                                                        |
| Special Requirements                                                                   |                                                                                                                                                                       |
| Legal Authorization Verification                                                       | The system should confirm that the user issuing the confiscation order possesses the required legal authority, ensuring adherence to applicable laws and regulations. |
