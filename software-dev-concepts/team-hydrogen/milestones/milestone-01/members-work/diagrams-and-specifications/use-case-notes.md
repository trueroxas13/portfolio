# Use Cases
- Register vehicle (ASSUMING this includes make payment)
- Renew vehicle registration (extends make payment, includes generate invoice, register vehicle)
- Transfer vehicle registration (includes generate invoice, generalizes transfer registered vehicle and transfer unregistered vehicle)
- Transfer registered vehicle (extends make payment)
- Transfer unregistered vehicle (checking and retrieving foreign policy handled by this use case as well, includes register vehicle)
- Record insurance policy (includes generate acknowledgement)
- Record fitness certificate (includes generate acknowledgement)
- Create accident report
- Retrieve accident report
- Create confiscation order
- Make payment (this also covers generating the payment receipt)
- Generate invoice
- Generate acknowledgement receipt
