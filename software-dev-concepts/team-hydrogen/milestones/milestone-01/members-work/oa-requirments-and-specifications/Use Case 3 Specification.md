| Use case Id: 003                                        | report accident                                                                                                                                      |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brief Description                                       | This use case allows the vehicle owner to report an accident between two vehicles                                                                    |
| Primary actors                                          | Vehicle Owner, Insurance Company.                                                                                                                    |
| Trigger(s)                                              | Current vehicle owner enters the VIN of the registered vehicle and his QID.                                                                          |
| Preconditions:                                          | The accident must involve exactly two vehicles.There should be no dispute regarding fault.                                                           |
| Post-conditions:                                        | An accident report is generated and sent to the insurance company.Both parties and authorized workshops can access the report using the case number. |
| Normal Scenario                                         |                                                                                                                                                      |
| Actor Action                                            | System Response                                                                                                                                      |
| 1. At fault vehicle enter their VIN                     |                                                                                                                                                      |
| 2. At fault vehicle enter victim VIN                    | 3. find vehicle details                                                                                                                              |
|                                                         | 4. find registration information                                                                                                                     |
|                                                         | 5. ask to provide the date, time and location of the accident.                                                                                       |
|                                                         | 6. ask to provide a brief accident description.                                                                                                      |
| 7. At fault vehicle enters requested information.       | 8. record this information.                                                                                                                          |
|                                                         | 9. ask vehicle owner to confirm they are at fault.                                                                                                   |
| 10. vehicle owner confirms this information             | 11. store this information .                                                                                                                         |
|                                                         | 12. concurrently finds the insurance policy of the offending vehicle.                                                                                |
|                                                         | 13. create accident report with a unique case number.                                                                                                |
|                                                         | 14. send accident report to the insurance company.                                                                                                   |
| 15. insurance company sends an acknowledgement receipt. | 16. save acknowledgement receipt.                                                                                                                    |
|                                                         | 17. store report for both parties                                                                                                                    |
