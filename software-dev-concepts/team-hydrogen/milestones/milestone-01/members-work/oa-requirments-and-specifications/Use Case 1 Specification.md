| Use case Id: 001                                                                                                                                                                                                                                                                                                                    | register new vehicle.                                                                                                                        |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Brief Description                                                                                                                                                                                                                                                                                                                   | This use case allows a vehicle owner to register a new vehicle by providing necessary details, purchasing insurance, and completing payment. |
| Primary actors                                                                                                                                                                                                                                                                                                                      | Vehicle Owner, Insurance Company, qPay System                                                                                                |
| Trigger(s)                                                                                                                                                                                                                                                                                                                          | Vehicle owner purchases an insurance policy                                                                                                  |
| Preconditions:                                                                                                                                                                                                                                                                                                                      | Vehicle owner must have an insurance policy for the new vehicle.VIN must be valid and verified by the manufacturer.                          |
| Post-conditions:                                                                                                                                                                                                                                                                                                                    | A new registration number is assigned.The insurance policy is attached to the vehicle registration.                                          |
| Normal Scenario                                                                                                                                                                                                                                                                                                                     |                                                                                                                                              |
| Actor Action                                                                                                                                                                                                                                                                                                                        | System Response                                                                                                                              |
| 1. Vehicle owner purchases an insurance policy                                                                                                                                                                                                                                                                                      | 2. Record insurance policy                                                                                                                   |
| 3. insurance company enters the Vehicle Identification Number (VIN)                                                                                                                                                                                                                                                                 |                                                                                                                                              |
| 4. insurance company attaches a copy of the policy                                                                                                                                                                                                                                                                                  | 5. Record this information along with company data                                                                                           |
|                                                                                                                                                                                                                                                                                                                                     | 6. generate an acknowledgment receipt for the company                                                                                        |
| 7. No action needed (7.a.)                                                                                                                                                                                                                                                                                                          |                                                                                                                                              |
| Alternative flows:                                                                   7.a. If the vehicle is over two years old, workshop enters Vehicle VIN, certificate number and attaches a copy of the certificate, stores this information along with the workshop data, generates an acknowledgment receipt for the workshop. |                                                                                                                                              |
