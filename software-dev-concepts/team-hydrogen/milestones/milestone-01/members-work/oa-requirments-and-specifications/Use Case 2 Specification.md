| Use case Id: 002                                                                                                                                                                                                                                                                                        | Transfer Registered Vehicle Ownership.                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Brief Description                                                                                                                                                                                                                                                                                       | This use case handles the transfer of ownership for a previously registered vehicle from one owner to another.           |
| Primary actors                                                                                                                                                                                                                                                                                          | Vehicle Owner.                                                                                                           |
| Trigger(s)                                                                                                                                                                                                                                                                                              | Current vehicle owner enters the VIN of the registered vehicle and his QID.                                              |
| Preconditions:                                                                                                                                                                                                                                                                                          | All fines and invoices must be paid before initiating the transfer.Both the current and new owners must have valid QIDs. |
| Post-conditions:                                                                                                                                                                                                                                                                                        | Ownership is transferred                                                                                                 |
| Normal Scenario                                                                                                                                                                                                                                                                                         |                                                                                                                          |
| Actor Action                                                                                                                                                                                                                                                                                            | System Response                                                                                                          |
| 1. current owner enters the VIN of the registered vehicle                                                                                                                                                                                                                                               |                                                                                                                          |
| 2. current owner enters his QID number                                                                                                                                                                                                                                                                  | 3. initiate the transfer process (3.a.)                                                                                  |
|                                                                                                                                                                                                                                                                                                         | 4. check for any unpaid invoices for registration fees or traffic fines                                                  |
|                                                                                                                                                                                                                                                                                                         | 5. request the new owner's details (5.a.)                                                                                |
| 6. current owner provides the mobile phone number of new owner                                                                                                                                                                                                                                          | 7. assign the vehicle to the new owner                                                                                   |
|                                                                                                                                                                                                                                                                                                         | 8. designate the current owner as the ‘previous owner’                                                                   |
|                                                                                                                                                                                                                                                                                                         | 9 .designate the new owner as the ‘current owner’                                                                        |
|                                                                                                                                                                                                                                                                                                         | 10 . Generate a new registration sticker                                                                                 |
|                                                                                                                                                                                                                                                                                                         | 11 . create an invoice for the transfer fee.                                                                             |
| Alternative flows:                                3.a. If the retrieved information does not match the provided data, terminates session with the message “Incorrect Information”.                   5.a. If there are any unpaid bills, terminates the session with the message “Pay the bills first”. |                                                                                                                          |
