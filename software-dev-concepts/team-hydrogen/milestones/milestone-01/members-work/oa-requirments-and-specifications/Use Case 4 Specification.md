| Use case Id: 004                                                                       | issue confiscation.                                                                                                                                |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brief Description                                                                      | This use case describes the process of issuing a confiscation order for a vehicle due to red-light offenses.                                       |
| Primary actors                                                                         | Traffic Police Officer                                                                                                                             |
| Trigger(s)                                                                             | Traffic police officer enters a period and selects a red-light offense type                                                                        |
| Preconditions:                                                                         | 1. The system is configured with the criteria for determining confiscation orders based on red-light offenses.                                     |
| Post-conditions:                                                                       | The vehicle's registration is canceled. The vehicle owner is notified of the confiscation order. The order is broadcast to all police departments. |
| Normal Scenario                                                                        |                                                                                                                                                    |
| Actor Action                                                                           | System Response                                                                                                                                    |
| 1. Traffic officer enters the period                                                   |                                                                                                                                                    |
| 2. Traffic officer selects the redlight offence type                                   | 3. find list of vehicles that match criteria                                                                                                       |
| 4. Traffic officer selects vehicles that exceed a certain number of red-light offences | 5. create confiscating order for those vehicles                                                                                                    |
|                                                                                        | 6. ask for confirmation from traffic police                                                                                                        |
| 7. Traffic officer confirmations request                                               | 8. save confirmation                                                                                                                               |
|                                                                                        | 9. cancel registration of specified vehicles                                                                                                       |
|                                                                                        | 10. inform each vehicle owner of registration cancelation                                                                                          |
|                                                                                        | 11. broadcast orders to all police departments.                                                                                                    |
